# Simplified conversion demo

See the [root deployment guide](../README.md#5a-deploy-and-run-the-mvp) for prerequisites, configuration, generated sample data, pipelines, semantic model and report deployment.

This profile has four notebooks and two pipelines. It demonstrates file preparation, five SQL quality checks, metadata-only AI explanations and a person-started load into stand-in tables. It is not a live CSM deployment or an authenticated approval product.

All resource settings come from ignored `workspace.json`, generated by `tools/configure.py`. Original customer data and original workspace identifiers are not included.
